## Features

- `lambdaHandler`, `lambdaStreamHandler`, and `websocketHandler` hydrate the
  non-secret `variables` bundle into `process.env` before Datadog setup and
  secrets loading, so both can be configured from the bundle.
- No handler option is required; the presence of `CDK_ENV_VARIABLES` triggers
  it and its absence is a no-op.
- The fetch starts at cold start and the lifecycle awaits the cached promise.

Addresses issue #443.
