## Changes

- `lambdaHandler` accepts `logEvent: false` and `logResponse: false` to suppress the automatic info-level event and response logs for handlers that receive or return sensitive values
- `lambdaStreamHandler` accepts `logEvent: false`
- `websocketHandler` accepts `logEvent: false` and `logResponse: false`
