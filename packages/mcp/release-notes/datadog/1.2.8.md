## Changes

- **`hasDatadogEnv` recognizes every key source** (#513). `DD_API_KEY` and the
  `SECRET_<NAME>` / `<NAME>_SECRET` references that `getEnvSecret` resolves now
  count as present. A key held only in Secrets Manager (for example
  `DATADOG_API_KEY_SECRET`) turns on `expressHandler` response metrics.
  Detection reads variable names only and fetches nothing.
- **Jaypie errors from metric submission** (#516). A failed Datadog response or
  connection error rejects with `BadGatewayError` rather than a vanilla `Error`.
  `submitMetric`, `submitMetricSet`, and `submitDistribution` still catch and
  return `false`.
- Tests cover a Datadog 403 through `datadogService` returning
  `success: false` with a readable error.
