## Features

- `loadEnvVariables()` hydrates a non-secret configuration bundle into
  `process.env`. It no-ops unless `CDK_ENV_VARIABLES` is present, which
  `JaypieLambda` sets when the new `variables` prop is used.
- Real environment variables always win; the bundle fills only absent keys.
- Keys prefixed `SECRET_` are refused so credentials cannot travel this path.
- The bundle is fetched once per execution context via the Lambda Parameters
  and Secrets extension, falling back to the SSM SDK. An `s3://` pointer is
  also resolved.
- `clearEnvVariablesCache()` discards the cached bundle.

Addresses issue #443.
