## Changes

- `createLayeredStore().find` checks every layer for an exact alias before it
  tries plural/singular fallback in any layer. With `studio:test` and
  `jaypie:tests`, `find("tests")` returns `jaypie:tests` in place of
  `studio:test`, so a local skill cannot shadow an existing Jaypie skill under
  a different spelling (#558).
- `createSkillService` resolves through `find`, so `skill("tests")` follows the
  same order. Namespace-qualified aliases still search only their own layer.
