## Changes

- **`@jaypie/llm` 1.3.43**: `Llm.question` answers typed questions in
  TypeSafe's Jev shape, served natively by the new `typesafe` provider or
  emulated on any provider that returns structured JSON. A per-call `model` no
  longer follows `operate()` onto a fallback provider.
