## Changes

- **`sensitiveHeaders`** (#515) adds header names to the request log's redaction
  list. Matching is case-insensitive and the option is additive, so the defaults
  still apply:

  ```typescript
  expressHandler(controller, {
    sensitiveHeaders: ["x-hub-signature-256", "x-slack-signature"],
  });
  ```

- **`logBody: false`** omits the request body from the log, for a route that
  receives a third-party payload the log should not carry.
- The default list is published as `EXPRESS.HEADER.SENSITIVE`
  (`authorization`, `cookie`, `set-cookie`).
- Both options apply to `expressStreamHandler` as well.

Defaults are unchanged: without either option the handler logs exactly what it
logged before.
