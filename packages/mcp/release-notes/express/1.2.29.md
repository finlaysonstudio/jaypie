## Features

- `expressHandler` and `expressStreamHandler` hydrate the non-secret
  `variables` bundle into `process.env` before Datadog setup and secrets
  loading.
- No handler option is required; the presence of `CDK_ENV_VARIABLES` triggers
  it and its absence is a no-op.
- The fetch starts at cold start and request setup awaits the cached promise.

Addresses issue #443.
