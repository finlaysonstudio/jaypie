## Changes

- Remove the `/* eslint-disable no-redeclare */` blocks wrapping the
  `expressHandler` and `expressStreamHandler` overload signatures.
  `@jaypie/eslint` 1.2.6 turns the core rule off for TypeScript, where it
  cannot read an overload and `tsc` already rejects a genuine redeclaration.

No functional change.
