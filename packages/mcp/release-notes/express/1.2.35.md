# @jaypie/express 1.2.35

## Bug Fixes

- **Localhost origins in local environments**: `cors()` allowed localhost only when `PROJECT_ENV=sandbox` or `PROJECT_SANDBOX_MODE=true`. Browser requests carrying an `Origin` header from a dev server were rejected in `PROJECT_ENV=local`. The allowance now also applies when `isLocalEnv()` is true.

## Types

- **`CorsConfig.origin` accepts `RegExp`**: The runtime matcher already tested `RegExp` entries, but the type was `string | string[]`. The new `CorsOrigin` type is `string | RegExp | Array<string | RegExp>` and is exported alongside `CorsConfig`.
