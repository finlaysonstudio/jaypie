## Changes

- **Teardown before metric** (#629). `expressHandler` and
  `expressStreamHandler` call `log.teardown()` and `untag("handler")` before
  `await submitMetric`. Previously the metric round trip held the session open,
  so a concurrent request's `init()` started a new session that this request's
  teardown then ended, dropping the newer request's later `log.report` calls.
  Lambda (one request per process) was unaffected; local servers and supertest
  suites with a Datadog key set were.
