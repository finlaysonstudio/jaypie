## Changes

- `fabricTool` accepts `external: true`: the produced tool carries the
  service's name, description, JSON Schema parameters, `message`, and
  `readOnly`, but no `call` — the definition travels to the provider while
  execution happens elsewhere (a browser, a device, a human). The service
  function is never invoked. Pairs with `@jaypie/llm`'s suspend/resume loop
  (issue #473): the operate loop parks when the model calls an external tool.
- The structural `LlmTool` type in `@jaypie/fabric/llm` becomes the same
  discriminated union `@jaypie/llm` declares (`LlmCallableTool` with required
  `call`, `LlmExternalTool` with `external: true` and no `call`), both newly
  exported. Shape-match preserved; still no dependency edge on `@jaypie/llm`.
