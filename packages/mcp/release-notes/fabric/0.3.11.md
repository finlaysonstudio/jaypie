## Changes

- **`@jaypie/fabric/websocket` now resolves.** The subpath shipped declarations
  with no `index.js` or `index.cjs`, so both `import` and `require` threw
  `ERR_MODULE_NOT_FOUND`. `websocket` had been added to the declaration entry
  list without a matching JS build config
- `rollup.config.js` derives every output from a single `entries` list, so a new
  subpath cannot reach `dist` in some shapes and not others. Config count drops
  from 34 to 11
- The JS builds are multi-entry, so code reachable from two entries is emitted
  once under `dist/<format>/chunks/` rather than duplicated into each subpath
  directory
- The build no longer exhausts the default V8 heap. Thirty-four configs each
  retained their own TypeScript program for the life of the process; the build
  now peaks near 700 MB
