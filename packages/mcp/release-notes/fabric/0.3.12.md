## Changes

- **`services` allowlist** (#539). `createMcpServerFromSuite` accepts
  `services?: string[]` to expose a subset of a suite. The new
  `selectServiceFunctions(suite, { services })` export holds the shared
  selection logic.

- **Stale sparse index keys are removed** (#533). When a partition key source
  field is missing, `populateIndexKeys` deletes the index key and its `Sk`
  companion instead of preserving whatever the entity carried in. When only a
  sort key source field is missing, it deletes the `Sk` attribute.
- An index with no partition key value no longer gets an orphan `Sk` attribute
  on a new entity.
- The input entity is not mutated.
