## Changes

- Two derived-event tests drew 1000 purchases hoping to observe a chargeback
  chain, then guarded every assertion behind a length check. Both exceeded the
  5s timeout under full-suite load. Output is a function of the seed, so a
  100-purchase sample known to hold the whole chain replaces the large sample
  drawn in hope of one.
- Assertions are unconditional, and depth groups are selected by event type and
  parent type rather than by the depth under test, which had made the depth-3
  check tautological. Both tests now require a representment to have drawn a
  second chargeback.
- 1099ms and 897ms become 109ms and 107ms, with strictly more asserted.

Tests only. No functional change.
