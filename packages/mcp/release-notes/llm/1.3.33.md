# @jaypie/llm 1.3.33

## Fixed

- Anthropic responses are marked as native structured output only when the
  request carried `output_config.format`. `effort` also rides `output_config`,
  and the legacy `structured_output` tool fallback preserves it, so every call
  after the first cached rejection was read on the native text path and
  returned `content: undefined` (#508).
- `extractStructuredOutput` falls through to the `structured_output` tool block
  when a response marked native carries no text block.
