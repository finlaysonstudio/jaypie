## Changes

- `tallyOperate` returns before building a payload when `log.sessionActive` is
  `false`, so `operate()` and `stream()` outside a Jaypie handler no longer
  produce `[logger] tally() called without active session` at trace (issue #522)
- Behavior inside a handler is unchanged; the guard compares against `false`, so
  a logger predating `@jaypie/logger` 1.2.24 still tallies
