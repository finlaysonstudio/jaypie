## Changes

- `MODEL.OPUS` names `claude-opus-5-5`, superseding `claude-opus-5`. The tier alias moves rather than gaining a new key, so every `MODEL.OPUS` consumer follows, including the Anthropic hot test, the document suite, and the live capability matrix
- `COST["claude-opus-5-5"]` prices the model at $4.00 input, $20.00 output, $5.00 five-minute cache write, $8.00 one-hour cache write, and $0.20 cache read per million tokens. Anthropic reads cache on Opus 5.5 at 0.05x input, half the standard 0.1x multiplier
- `MODEL.SOL` names `gpt-6-sol` and `MODEL.LUNA` names `gpt-6-luna`, superseding `gpt-5.6-sol` and `gpt-5.6-luna`. `PROVIDER.OPENAI.DEFAULT` is `MODEL.SOL` and follows. `MODEL.TERRA` stays on `gpt-5.6-terra`: OpenAI has released no GPT-6 model in that tier
- `MODEL.OPENROUTER.LUNA` names `openai/gpt-6-luna`, keeping the gateway route on the same tier's current model. Verified served on the OpenRouter models endpoint
- `COST["gpt-6-luna"]` at $0.10 input, $0.50 output, $0.01 cache read, and `COST["gpt-6-sol"]` at $2.00 input, $10.00 output, $0.20 cache read per million tokens. Both launched at standard rates with no promotional window footnoted, unlike GPT-5.6 Sol. Their long-context tiers are excluded as the long-prompt surcharge
- `COST["claude-opus-5"]`, `COST["gpt-5.6-sol"]`, and `COST["gpt-5.6-luna"]` remain so historic usage records stay replayable
