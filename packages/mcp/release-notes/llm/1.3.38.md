## Changes

- `MODEL.ASTRA` is `gpt-6-astra`, added alongside `MODEL.SOL` rather than
  replacing it. Astra is a new-generation flagship at twice Sol's rate, so the
  two coexist as distinct offerings and `PROVIDER.OPENAI.DEFAULT` stays on
  `MODEL.SOL`. The catalog addition puts Astra in the live capability matrix and
  the OpenAI hot tests.
- `COST` gains `gpt-6-astra` at $10.00 input / $50.00 output per million tokens
  with $1.00 cache reads.
- `reasoning.effort` follows the gpt-6 ladder: `highest` reaches `max`, the rung
  above `xhigh`, and `lowest` clamps to `low` because gpt-6 drops `minimal`. The
  gpt-5 line is unchanged.
- `PROVIDER.OPENAI.MODEL_MATCH_WORDS` gains `astra`, matching how `sol`, `terra`,
  and `luna` are carried.

- CI no longer shards Mistral. The provider's availability does not survive a
  per-push run — a `Rate limit exceeded` 429 across all seven cells, and an
  entitlement refusal before that — so `npm-check.yml` and `npm-deploy.yml` drop
  the `mistral` group. Mistral models stay cataloged, priced, and adapter-tested;
  `APP_GROUP=mistral npm run test:llm:matrix` still reaches the live cells.

## Testing

- `determineModelProvider` resolves the id on the existing `gpt` match word;
  `astra` is added for the bare name.
- `maxOutputTokens` leaves OpenAI unset by policy: Astra's 128K ceiling is not a
  low ceiling, and streaming requests carry no limit.
- The matrix takes no `MATRIX_EXPECT` entry. Astra advertises the same input
  modalities as Sol (text and image), and Sol passes every capability cell.
- Deprecated `PROVIDER.OPENAI.MODEL` size tiers and the `MODEL.GPT*` aliases are
  unchanged by policy.
