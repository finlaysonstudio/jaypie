## Changes

- `MODEL.GEMINI_ARGON` catalogs `gemini-4-argon`, Google's first Gemini 4 model.
- `COST["gemini-4-argon"]` carries the standard rate ($4 input, $20 output, $0.20 cache read per 1M). The introductory rate ($2/$10) through 2026-11-30 is excluded per policy.
- Gemini 4 takes `thinkingLevel` like Gemini 3 but rejects `MINIMAL`, so `effort: "lowest"` collapses onto `LOW` (papered). `toGeminiThinkingLevel` accepts `{ minimal: false }`.
- Gemini 4 uses native `responseJsonSchema` with tools (the `format` + tools combo), matching Gemini 3.
- Gemini 4 resolves a 65,536 output-token maximum on the streamed transport.

## Testing

- Verified live 2026-10-18: `MINIMAL` returns 400, `LOW` and `HIGH` succeed, and `responseJsonSchema` with tools returns schema-valid JSON.
