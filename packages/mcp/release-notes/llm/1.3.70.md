## Changes

- **`MODEL.FIREWORKS.GPT_OSS`** and **`MODEL.FIREWORKS.INKLING`** are
  `@deprecated`. Fireworks retired `gpt-oss-120b` and `inkling` from serverless
  on 2026-11-07; requests return "Model not found". The ids stay exported so
  existing references compile, and the live matrix skips them.
- Live capability matrix (`test/matrix.ts`):
  - A refusal that returns no text (thrown as `LlmIncompleteError`) is
    inconclusive, like a refusal that settles. It previously failed the cell.
  - A cell that misses its expectation or settles inconclusive retries up to
    `APP_RETRIES` more times (default 2). Earlier attempts print under FLAKY
    and append to the GitHub Actions job summary.
- OCR harness (`test/ocr.ts`): failed tests retry the same way and report a
  FLAKY block; text checks collapse whitespace before matching.

## Upgrade

- Replace `MODEL.FIREWORKS.GPT_OSS` and `MODEL.FIREWORKS.INKLING` with another
  `MODEL.FIREWORKS.*` id, or a dedicated Fireworks deployment.
