## Changes

- `operate()` logs `[operate] Model returned text despite format on turn ...` at
  **debug** rather than warn on both recovery paths: fresh-context conversion
  (`supportsStructuredOutputConversion`) and the corrective structured_output
  turn (`supportsStructuredOutputRetry`). Both paths usually settle
  successfully, so warn implied an operator-visible failure where none occurred
- `[operate] Fresh-context conversion did not yield structured output` remains
  at warn: that path indicates the recovery itself failed
