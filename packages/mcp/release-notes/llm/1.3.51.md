## Changes

- Per-call `providerOptions` on `operate` and `ocr` reach the primary only, its linger pass included. Previously every fallback received them verbatim, so options shaped for one provider (OpenAI `reasoning`) broke a fallback on another (Gemini rejected `reasoning` in `generation_config`) and the chain provided no resilience (#591)
- `LlmFallbackConfig` gains `providerOptions`, sent only to that entry
- Fallbacks derived from a `model` array carry no `providerOptions`
- `MODEL.FIREWORKS.DEEPSEEK` is now `accounts/fireworks/models/deepseek-v4p1-flash`, the same id as `DEEPSEEK_FLASH`. Fireworks withdrew `deepseek-v4-pro-0813` from serverless (404 "Model not found"); its `COST` entry stays

## Testing

- `npm run test -w packages/llm`: new specs cover operate (cross-provider fallback, per-entry options, linger pass) and ocr scoping
- Fireworks hot spec passes for every catalog id, deepseek-v4p1-flash included
