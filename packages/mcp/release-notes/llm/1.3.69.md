## Changes

- **`MODEL.FABLE`** now points at `claude-fable-5-2` instead of
  `claude-fable-5-1`. Fable 5.2 replaces 5.1 at a lower price.
- **`COST`** adds `claude-fable-5-2` at $8 input, $40 output, $0.20 cache
  read, and $10 / $16 cache write for the 5-minute / 1-hour TTL, all per MTok.
  The `claude-fable-5-1` entry stays in place.
- **`MODEL.MYTHOS`** now points at `claude-mythos-5-2` instead of
  `claude-mythos-5`, keeping it in step with Fable. Mythos is available only
  to verified organizations.
- **`COST`** adds `claude-mythos-5-2` at Fable 5.2's rates, and
  `claude-mythos-5-1` at Fable 5.1's rates ($10 / $50, $0.25 cache read,
  $12.50 / $20 cache write).

## Testing

- `npm run test -w packages/llm` passes. Both catalog ids resolve to the
  anthropic provider and have prices.
