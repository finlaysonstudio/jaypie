## Changes

### Claude Haiku 5.5

- `MODEL.HAIKU` is now `claude-haiku-5-5`, superseding `claude-haiku-4-5`. Every `MODEL.HAIKU` consumer follows, including the live matrix.
- `COST` prices `claude-haiku-5-5` at $0.10 input and $0.50 output per million tokens, with cache reads at $0.01 and cache writes at $0.125 (5m) and $0.20 (1h). This is the rate card for prompts up to 100K tokens; the $0.50 / $2.50 long-prompt rate is not modeled. The `claude-haiku-4-5` entry stays so historic usage remains replayable.
- Streaming requests resolve Haiku 5.5's 128,000 output-token maximum. Haiku 4.5 keeps 64,000.
- `AnthropicAdapter` strips `temperature` for Haiku 5 and later, which reject non-default sampling parameters with a 400.
- The deprecated `PROVIDER.ANTHROPIC.MODEL.TINY` tier stays frozen on `claude-haiku-4-5`.

### Behavior to expect from the new model

- Thinking is adaptive and on by default, and it counts toward `max_tokens`. A caller passing a small explicit output limit may see a response stop before any text.
- Cost per token drops tenfold against Haiku 4.5, though the newer tokenizer counts the same text as about 30% more tokens.

## Testing

- `maxOutputTokens.spec.ts` covers the 128,000 ceiling for `claude-haiku-5-5` alongside 64,000 for `claude-haiku-4-5`.
- `AnthropicAdapter.spec.ts` covers the temperature strip for `claude-haiku-5-5`.
- Verified live: `claude-haiku-5-5` passes all seven capability matrix cells.
