## Changes

- `classifyProviderError` now classifies a floating point NaN generation failure as retryable

Fireworks reports numerical overflow during sampling as `Floating point NaN (not-a-number) is detected in generation.` The fault does not reproduce reliably, so the shared classifier returns `ErrorCategory.Retryable` and the operate loop spends a transient retry instead of failing the call.
