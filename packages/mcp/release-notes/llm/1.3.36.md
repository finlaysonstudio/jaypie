## Changes

- `MODEL.GEMINI_FLASH` is `gemini-3.8-flash`, superseding `gemini-3.7-flash` in
  the same tier. Every `MODEL.GEMINI_FLASH` consumer follows, including
  `PROVIDER.GOOGLE.DEFAULT`, the live capability matrix, and the Google hot
  tests.
- `COST` gains `gemini-3.8-flash` at $1.50 input / $7.50 output per million
  tokens with $0.15 cache reads, the standard rates that take over when the
  introductory pricing ends on 2026-12-31. The `gemini-3.7-flash` entry stays in
  place so historic usage records remain replayable.
