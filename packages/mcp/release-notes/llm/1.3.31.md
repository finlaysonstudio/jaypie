## Changes

- Fireworks joins Bedrock and OpenRouter as a collective block in the live
  capability matrix: the block passes on a row and column majority rather than
  on every cell. NEMOTRON's structured output is nondeterministic (8 for 8 on
  resample 2026-08-21, yet lost in CI on 2026-08-19 and 2026-08-21), so no
  single per-cell expectation is correct for it. One flaky cell no longer fails
  the run; a model that breaks across the board, or a capability that breaks
  across the block, still does.
- Collective evaluation moved to `test/collective.ts` with unit coverage in
  `test/__tests__/collective.spec.ts`, replacing the duplicated per-provider
  OpenRouter and Bedrock paths in `test/matrix.ts`.
- Effort papering that follows from a provider's native scale (Fireworks and
  Grok `highest`, Gemini 3.x `highest`, Mistral's none/high binary, Anthropic
  `lowest`) no longer logs. Only model-dependent papering, such as OpenAI
  clamping `highest` on a model predating `xhigh`, is recorded, at debug.
