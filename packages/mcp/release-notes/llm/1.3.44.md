## Changes

### New Features

- `Llm.ocr(document, options?)` is a fifth entry point: a document in,
  per-page markdown out. Static and instance forms mirror `question`,
  including `model` array sugar, `fallback`, `retry`, and `signal`. The
  document (an `https://` URL, a `data:` URI, an S3 key, a local path, or the
  `{ file }` / `{ image }` objects `operate()` accepts) is resolved once before
  the fallback chain runs.
- New provider `llamacloud` serves LlamaParse over the LlamaCloud Parse API
  v2 with `LLAMA_CLOUD_API_KEY` and match words `llamacloud`, `llamaindex`,
  and `llamaparse`. A parse is a job: submitted by `source_url` or multipart
  upload, polled from one second backing off to five, then fetched. It
  implements `ocr` only; `send` throws `NotImplementedError`. The client is
  `fetch` against four routes; no SDK dependency is taken.
- The LlamaParse **tier is the model id**: `MODEL.LLAMAPARSE.FAST`,
  `COST_EFFECTIVE`, `AGENTIC` (the provider default), and `AGENTIC_PLUS`.
  A chain such as `[MODEL.MISTRAL.OCR, MODEL.LLAMAPARSE.COST_EFFECTIVE]`
  therefore reads as a plain model list and routes through
  `determineModelProvider`.
- The API version is pinned per tier in `PROVIDER.LLAMACLOUD.VERSION`; each
  tier accepts its own dated versions and rejects the others (verified live
  2026-09-19). `providerOptions.version` overrides it per call, and the
  response `model` is `<tier id>@<version>`.
- Common shape: `markdown`, 1-indexed `pages[]` with `header`, `footer`,
  `images`, `success`/`error`, and the vendor page at `raw`; `images[]`;
  `usage` with `pages`, LlamaParse `credits`, and `cost`; `responses[]`; and
  the `provider`/`model`/`fallbackAttempts`/`fallbackUsed` fields `operate`
  carries. Options: `pages` (`[1, 3]` or `"1,3,5-10"`), `tables`
  (`"markdown"` or `"html"`), `images` (download extracted images as `data:`
  URIs), `timeout` (asynchronous job ceiling, default ten minutes), and
  `providerOptions` spread last onto the vendor request.
- `PAGE_COST` prices document-extraction engines in USD per 1,000 pages,
  keyed by literal id: `mistral-ocr-4-1` at $4 and the four LlamaParse tiers
  at $1.25, $3.75, $12.50, and $56.25 (credits at
  `PROVIDER.LLAMACLOUD.CREDIT_COST`, $1.25 per 1,000). A LlamaParse job's
  recorded credits win over the per-page estimate.
- `DEFAULT.OCR` names the engine `Llm.ocr` uses when neither a provider nor a
  model is given: Mistral OCR, one synchronous call and the cheapest markdown
  tier on offer.

### Changed

- `MistralProvider.ocr()` takes the common `(document, options)` signature
  and returns the common shape. The provider-specific `{ markdown, model,
pages, raw }` return shipped in 1.3.43 and is gone: `raw` is
  `responses[0]`, and the 0-indexed `pages[].index` is the 1-indexed
  `pages[].page` with the vendor page at `pages[].raw`. `MistralOcrPage` and
  `MistralOcrResponse` are no longer exported. `OcrRequest` widens to the full
  Mistral `OCRRequest` field set.
- Client failures on Mistral OCR classify through the chat adapter into the
  typed `LlmError` family, and both engines share one retry loop
  (`src/ocr/runOcrAttempts.ts`), so `retry` and `signal` mean the same thing
  on each. A LlamaParse job that reports `FAILED` throws
  `LlmUnrecoverableError` with the API's message, `CANCELLED` throws
  `LlmAbortError`, and a job that outlives `timeout` throws
  `LlmTransientError` so a chain can try the next engine.
- `loadFileData` and `getExtensionForMimeType` are exported from the upload
  helpers for reuse; `LlmProvider` gains an optional `ocr`.

### Internal

- `MODEL.LLAMAPARSE.*` join `MODEL.MISTRAL.OCR` in `MATRIX_EXCLUDE`: a
  document-extraction engine implements neither `operate()` nor `send()`, so
  every capability cell would fail by construction. They are exercised by
  `tsx test/ocr.ts` (`npm run test:llm:ocr`) and the provider hot specs.
- Both CI workflows pass `LLAMA_CLOUD_API_KEY` from the
  `CICD_LLAMA_CLOUD_API_KEY` org secret; the LlamaCloud hot spec skips until
  the secret exists.

## Testing

- Live, 2026-09-19 (`npm run test:llm:ocr`): `page.pdf` and `page.png`
  through Mistral OCR and all four LlamaParse tiers, every run reading the
  fixture text, plus a chain falling from an unknown tier to Mistral. 11 of 11
  passed. Mistral answered in about one second at $0.004 per page; LlamaParse
  completed in 3 to 5 polls (6 to 15 seconds) at 1, 3, 10, and 45 credits per
  page by tier.
- New unit coverage for page-selection parsing, document resolution (URL,
  data URI, S3, disk, inline data, PDF trimming), the shared retry loop, the
  LlamaCloud client's routes and status-to-error mapping, the provider's
  submit/poll/fetch cycle (including fast-tier text, failed pages, image
  download, per-tier version, timeout, and abort), the reworked Mistral OCR
  mapping, `Llm.ocr` routing and fallback, and provider routing for every new
  id.
