## Changes

- `warn` is reserved for a call that is running but not as expected. A path
  that recovers and delivers the requested result logs at `debug`
- Demoted to `debug`: the transient-retry notice on both loops (`API call
  failed. Retrying in ...`, `Stream request failed. Retrying in ...`) and the
  per-call notice that an adapter is serving `format` through
  `structured_output` emulation (Anthropic, Fireworks, Google, Mistral,
  OpenRouter). The emulation notice repeated on every call for the rest of the
  session once a model was demoted to the fallback
- Unchanged at `warn`: the one-time provider rejection that causes the
  demotion, both rate-limit waits, discarded image/file/unknown content, tool
  execution errors, turn and tool-error budget stops, `onProgress`/`onExchange`
  callback throws, exchange persistence failures, and failed fresh-context
  conversions
- The level policy is documented in the package CLAUDE.md under Operate Logging
