## Changes

- `MODEL.FIREWORKS.QWEN` is now `accounts/fireworks/models/qwen3p8-max`.
  Fireworks withdrew `qwen3p7-plus` from serverless on 2026-09-10 without an
  announcement; every request answered "Model not found, inaccessible, and/or
  not deployed"
- `MODEL.FIREWORKS.MINIMAX` is now `accounts/fireworks/models/minimax-m3`, the
  successor Fireworks names for `minimax-m2p7` (withdrawn 2026-08-27)
- `COST` prices `qwen3p8-max` at $2.00 input, $6.00 output, $0.25 cached input
  read per million tokens, five times the Qwen 3.7 Plus rate, and
  `minimax-m3` at $0.30 input, $1.20 output, $0.06 cached input read. The
  retired ids keep their `COST` entries per policy
- `minimax-m3` leaves `MATRIX_EXCLUDE` and runs the live capability matrix
  again. It advertises no image input, so its image cell stays skipped;
  `qwen3p8-max` runs the image cell
