## Changes

- `MODEL.FIREWORKS.GLM` names `accounts/fireworks/models/glm-5p3`, superseding `glm-5p2`. `PROVIDER.FIREWORKS.DEFAULT` is `MODEL.FIREWORKS.GLM` and follows
- `MODEL.FIREWORKS.GLM_FLASH` names `accounts/fireworks/models/glm-5p3-flash`
- `MODEL.FIREWORKS.DEEPSEEK_FLASH` names `accounts/fireworks/models/deepseek-v4p1-flash`, alongside `MODEL.FIREWORKS.DEEPSEEK` (`deepseek-v4-pro-0813`)
- `MODEL.OPENROUTER.MIMO` names `xiaomi/mimo-v2.6-flash`. OpenRouter routes stay unpriced
- `COST` prices `glm-5p3` at $1.40 input, $4.40 output, $0.26 cache read; `glm-5p3-flash` at $0.15 input, $0.50 output, $0.03 cache read; `deepseek-v4p1-flash` at $0.30 input, $1.20 output, $0.006 cache read per million tokens (Fireworks standard serverless rates)
- `COST["accounts/fireworks/models/glm-5p2"]` remains so historic usage records stay replayable
- Matrix expectations: `GLM_FLASH` and `DEEPSEEK_FLASH` advertise image input and skip only `pdf`; `GLM` (`glm-5p3`) advertises no image input and skips both
