## Changes

- `operate()` settles `status: "incomplete"` with `error.reason: "incomplete"` (502) when the provider stops the model before it finishes. OpenAI and xAI report `status: "incomplete"` with `incomplete_details.reason` (`max_output_tokens`, `content_filter`); the partial text stays in `content` and `error.detail` names the reason
- Previously the loop completed with the truncated text, and a structured request surfaced as prose that failed the format contract ("OCR emulation did not return JSON")
- `stream()` emits an error chunk on the `response.incomplete` event and settles the exchange incomplete; usage from that event still tallies
- `Llm.ocr` emulation wraps a settled error body in `LlmUnrecoverableError` so a fallback chain logs the provider's reason and moves to the next engine
- New `LlmResponseErrorReason.Incomplete` and `ParsedResponse.incompleteReason` for adapters
