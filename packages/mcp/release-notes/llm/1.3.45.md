## Changes

- `operate()` settles `status: "incomplete"` with `error.reason: "incomplete"` (502) when the provider stops the model before it finishes; the partial text stays in `content` and `error.detail` names the provider's reason
- Every adapter reports it: OpenAI, xAI, and Meta from `status: "incomplete"` plus `incomplete_details.reason` (`max_output_tokens`, `content_filter`); Anthropic from `stop_reason` `max_tokens` or `refusal`; Google from `finishReason` `MAX_TOKENS` or a safety finish; Bedrock from `max_tokens` or a guardrail stop; Fireworks, Mistral, and OpenRouter from `finish_reason` `length` or `content_filter`
- Previously the loop completed with the truncated text, and a structured request surfaced as prose that failed the format contract ("OCR emulation did not return JSON")
- `stream()` emits an error chunk from the same stop event on every provider and settles the exchange incomplete; usage from that event still tallies
- `Llm.ocr` emulation wraps a settled error body in `LlmUnrecoverableError` so a fallback chain logs the provider's reason and moves to the next engine
- New `LlmResponseErrorReason.Incomplete` and `ParsedResponse.incompleteReason` for adapters
