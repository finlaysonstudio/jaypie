## Changes

- `MODEL.FIREWORKS.MUSE_GLIMMER` removed. `muse-glimmer-30b` ignores the native
  `response_format` and writes the corrective turn's tool call as text, so
  `operate()` never receives structured output (0 for 6 live). Its `COST` entry
  is retained, so a caller passing the literal id can still price it.
- The live matrix no longer skips the PDF cell for `MODEL.GROK`. Grok 4.6 reads
  the fixture 9 for 9; the skip tracked a 4.5 regression.
- Documentation names models by `LLM.MODEL.*` alias rather than by literal id.
  Literal ids remain where the id itself is the subject: provider keyword
  matching, `COST` keys, version-gated behavior, and documented per-model
  defects.
