## Changes

- `@jaypie/testkit/mock` no longer fails to load when `@jaypie/aws`,
  `@jaypie/datadog`, `@jaypie/dynamodb`, `@jaypie/express`, `@jaypie/llm`,
  `@jaypie/textract`, or `amazon-textract-response-parser` is not installed.
  Wrapped mocks return their fallback values and pass-through exports (e.g.
  `LLM`, `EXPRESS`, `toolkit`) are `undefined` for an absent package.
- Those packages are declared as optional peers, so strict package managers
  resolve them when present.
- `@jaypie/kit` and `@jaypie/logger` move from optional peers to
  `dependencies`, joining `@jaypie/errors`. The core mocks need all three.
- `@jaypie/testkit/testSetup` is now exported, matching the documented
  `test.setupFiles: ["@jaypie/testkit/testSetup"]`. It registers every matcher.
