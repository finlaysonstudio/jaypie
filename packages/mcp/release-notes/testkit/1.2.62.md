## Changes

- `@jaypie/testkit/mock` exports a mocked `MistralProvider`, matching the new
  first-class Mistral provider in `@jaypie/llm`
- `@jaypie/testkit/mock` re-exports `LlmAbortError`, matching the `@jaypie/llm`
  1.3.24 cancellation taxonomy
- `@jaypie/testkit/mock` exports a mocked `useExchangeStore`, also present as
  `Llm.useExchangeStore`, so a host's bootstrap registration is inert and
  assertable under test
- `createMockTool({ external: true })` produces a call-less external tool,
  matching the `LlmCallableTool | LlmExternalTool` union `@jaypie/llm` 1.3.24
  introduces. Overloads keep every other form returning `LlmCallableTool`, so
  existing `tool.call(...)` in consumer tests still typechecks
