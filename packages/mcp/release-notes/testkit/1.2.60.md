## Changes

- The `vitest` module augmentation for Jaypie matchers now ships in `dist`. Importing `@jaypie/testkit` anywhere in a TypeScript program types every matcher, so `expect(x).toBeFunction()` no longer fails `tsc --noEmit` with `TS2339`. Previously the augmentation existed only in source and never reached the published package.
- Augments Vitest 3+ `Matchers` and `AsymmetricMatchersContaining` in addition to `Assertion`, covering `expect(x).toBe*`, `expect(x).not.toBe*`, `expect.toBe*`, and `expect.not.toBe*`.
- Added a consumer-perspective regression test that runs `tsc` against the built `dist` with package sources out of scope.

## Notes

The augmentation is in scope only for files compiled alongside an import of the package. Keep `vitest.setup.ts` inside the tsconfig `include`, per `skill("subpackage")`.

Fixes #460.
