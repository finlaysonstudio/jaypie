## Changes

- `@jaypie/errors` moved from an optional peer to a `dependency`. The
  `toThrow*Error` matchers import it at module load, so installing only
  `@jaypie/testkit` and importing `matchers` failed with
  `Cannot find package '@jaypie/errors'` (#529).
- Added `publishedImports.spec.ts`, which requires every package the root
  entry imports at runtime to be a `dependency` or a required peer.
