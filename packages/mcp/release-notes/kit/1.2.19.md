## Changes

- `placeholders()` keeps a `{{ key }}` handlebar only when the resolved value is
  `undefined`. A present `""`, `0`, `false`, or `null` renders through
  `String()`. Previously any falsy value left the literal handlebar in the
  output (#526).
- The internal path lookup stops only when the path breaks (a non-object or an
  absent key), so falsy nested values such as `{{ user.count }}` with
  `{ user: { count: 0 } }` resolve.
- Whitespace handling is unchanged: `{{ name }}` and `{{name}}` resolve the same
  key, and a missing key keeps its original spacing.
