## Changes

- `src/core.ts` no longer imports and re-exports `log` from `@jaypie/logger`. The
  re-export was never reachable from `src/index.ts`, so `rollup-plugin-dts`
  tree-shook it and warned that the import was unused on every build.
- `jaypieHandler` imports `log` directly from `@jaypie/logger`. It is the same
  singleton, so behavior is unchanged.
- No public export changed. `log` was not on the package entry point before or
  after.
