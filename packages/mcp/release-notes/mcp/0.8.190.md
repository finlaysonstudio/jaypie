## Changes

- **Skills**: `monorepo`, `cdk`, `cicd-actions`, `cicd-deploy`, `dynamodb`, and `jaypie` name `packages/cdk` as the single location for the CDK package (#623)
- **`monorepo`**: drops `stacks` as a workspace directory name; limits `workspaces/` to repositories whose `packages/` publish to npm; notes that the root `package.json` and vitest globs cover `packages/*` only
- **`cicd-actions`**: `cdk-deploy` defaults `working-directory` to `packages/cdk`; `web-deploy` defaults to `packages/cdk/cdk-outputs.json` and `packages/web/dist`
