## Changes

- `skill("cicd-actions")` publishes a `web-deploy` composite action and lists it in the directory structure. `skill("web")` pointed at a deployment pattern that did not exist, leaving the anti-`BucketDeployment` model with a provisioning half and no shipping half. `skill("cicd-deploy")` now gains a Web Content Deployment section and runs the action after `cdk-deploy` in both workflow templates. Fixes #457.
- `setup-environment` accepts and exports `PROJECT_SPONSOR` as a required input. Copying the action verbatim previously deployed stacks named `cdk-undefined-...`, and stack names are immutable. `skill("variables")` lists the variable and the generated stack name format. Fixes #459.
- `skill("monorepo")` and `skill("subpackage")` replace the root `vitest.workspace.ts` with `test.projects` in `vitest.config.ts`. Vitest 3 deprecated the workspace file and Vitest 4 removed it. Fixes #458.
- `skill("subpackage")` includes `vitest.setup.ts` in the tsconfig `include` and explains why the matcher type augmentation depends on it. Relates to #460.
