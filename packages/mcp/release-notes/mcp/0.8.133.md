## Changes

- The llm skill names models as `LLM.MODEL.*` rather than repeating literal
  ids, which go stale the day an alias is repointed. The provider table lists
  each `PROVIDER.*.DEFAULT` alias; literal ids remain only where the id itself
  is the subject, such as provider keyword matching and `COST` keys.
