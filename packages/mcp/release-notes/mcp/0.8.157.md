## Changes

- **`dynamodb`** adds "Keep Table Properties Stable": any CloudFormation update
  to a table fails once a migration creates a GSI.
- **`migrations`** notes migration-owned index behavior and recovery for stacks
  deployed before `@jaypie/constructs` 1.2.85.
- **`cdk`** notes that per-build tags skip DynamoDB tables (#548).
