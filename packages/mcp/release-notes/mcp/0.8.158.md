## Changes

- **`dynamodb`** replaces "Keep Table Properties Stable" with "Share Indexes
  Between CDK and Runtime" (`indexes: getAllRegisteredIndexes()`) and "Indexes
  Created Outside CDK" (failure and recovery). Local Development creates the
  table with `createTable()` from the registry and runs the migration seed,
  replacing the AWS CLI script that created no GSIs (#552).
- **`migrations`** documents describe-only grants, the synth warning for tables
  without indexes, and a seed module shared by the migration and local scripts.
- **`cdk`** removes the note that per-build tags skip DynamoDB tables.
- **`secrets`** adds External Secrets (`external: true` with a CI
  `put-secret-value` step) and SSOSync Credentials, and notes that env-sourced
  values are written into the template (#551).
