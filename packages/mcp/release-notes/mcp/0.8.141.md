## Changes

- The Datadog suite moved to `@jaypie/datadog` (#512). `@jaypie/mcp` now imports
  `datadogService` from that package and registers it unchanged. The MCP tool
  surface is identical.
- The docs suite throws `BadRequestError` rather than a vanilla `Error` for a
  missing parameter or an unknown command (#516).
