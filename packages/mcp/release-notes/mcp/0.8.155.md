## Changes

- **Bundled builds** find `skills/` and `release-notes/` beside the bundle when
  the package copy is absent. `MCP_BUILTIN_SKILLS_PATH` and
  `MCP_RELEASE_NOTES_PATH` still win when set (#543).
- **`release_notes` help** is inlined, so a bundle no longer needs
  `suites/docs/release-notes/help.md`.
- **Warning** logged to stderr on the first `skill` or `release_notes` call
  when its directory is missing or empty, naming the directory and variable.
- **`@jaypie/mcp/assets`** exports `getMcpAssetPaths()` and
  `MCP_ASSET_DIRECTORY` for build scripts that copy the markdown beside a
  bundle.
- **`mcp` skill** documents the bundling copy step; the `express` skill's
  esbuild banner aliases its imports to avoid duplicate declarations.
- **`github` skill** documents the repository standard: the `main` ruleset,
  environment classes and deployment branch policies, and secrets and variables
  layered across organization, repository, and environment scopes. Linked from
  `cicd`, `cicd-environments`, `infrastructure`, and `skills`.
