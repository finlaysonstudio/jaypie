## Changes

- **`cicd-actions`** makes `project-nonce` `required: true` in
  `setup-environment` and fails with `::error::` when it is empty. The branch
  name and `prod` fallbacks are removed (#554).
- **`cicd-environments`** moves `PROJECT_NONCE` to Required Variables (8
  lowercase hex, unique per environment, `openssl rand -hex 4`) and adds it to
  the sandbox and production examples.
- **`cicd-deploy`** passes `project-nonce: ${{ vars.PROJECT_NONCE }}` in both
  deploy jobs, replaces hand-rolled `api-${env}-${nonce}` naming with the
  `JaypieStack` generated name, and adds One Install per Environment.
- **`variables`**, **`cdk`**, **`jaypie`**, **`recipe-api-server`**, and
  **`debugging`** use hex nonces in place of `dev`, `staging`, and `prod`.
- **`cdk`** documents the `@jaypie/constructs:projectNonceFormat` synth
  warning.
- **`github`** notes that `setup-environment` fails on an empty
  `project-nonce` instead of falling back.

## Upgrade

- Projects built from the previous `cicd-actions` template may have deployed
  branch-name nonces. Set `PROJECT_NONCE` on each GitHub environment. The new
  value creates a new install, so tear down the old stacks and buckets.
