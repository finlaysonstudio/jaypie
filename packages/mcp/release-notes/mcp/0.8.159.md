## Changes

- **`cicd-actions`** makes `project-nonce` `required: true` in
  `setup-environment` and fails with `::error::` when it is empty. The branch
  name and `prod` fallbacks are removed (#554).
- **`cicd-environments`** moves `PROJECT_NONCE` to Required Variables (8
  lowercase hex, unique per environment, `openssl rand -hex 4`) and adds it to
  the sandbox and production examples.
- **`cicd-deploy`** passes `project-nonce: ${{ vars.PROJECT_NONCE }}` in both
  deploy jobs, replaces hand-rolled `api-${env}-${nonce}` naming with the
  `JaypieStack` generated name, and adds One Install per Environment.
- **`variables`**, **`cdk`**, **`jaypie`**, **`recipe-api-server`**, and
  **`debugging`** use hex nonces in place of `dev`, `staging`, and `prod`.
- **`cdk`** documents the `@jaypie/constructs:projectNonceFormat` synth
  warning.
- **`github`** notes that `setup-environment` fails on an empty
  `project-nonce` instead of falling back.
- **`@jaypie/mcp/assets`** exports `getMcpBuildInfo()`, which returns
  `{ commit, version, versionString }` from the same build-time replacements the
  `version` tool reports. A consumer syncing `skills/` and `release-notes/`
  reads the build from the same package. The **`mcp`** skill documents it
  (#555).
- **`tildeskill`** documents that layered `find` checks every layer for an
  exact alias before plural/singular fallback (#558).
- **`tildeskill`** documents `createDynamoDbStore` from
  `@jaypie/tildeskill/dynamodb`, `syncSkills`, and `delete` semantics for every
  store. **`dynamodb`** notes that skills use `indexModelCategory` and that
  `registerSkillModel()` declares it (#557).
- **`tildeskill`** documents that `createSkillService` throws `BadRequestError`
  for an invalid alias and `NotFoundError` for a missing skill.
- **`release_notes("list")`** paginates. `limit` defaults to 50 and caps at
  200. Notes sort by package ascending, then version descending. A
  `Next page: release_notes("list", { cursor: "..." })` footer appears only
  when more notes exist, and its opaque cursor carries `package`,
  `since_version`, and `limit`. Invalid cursors and filters that conflict with
  the cursor return a bad request. The unfiltered first page drops from about
  61K to about 5.7K characters. The **`mcp`** and **`releasenotes`** skills
  document it (#556).

## Upgrade

- Projects built from the previous `cicd-actions` template may have deployed
  branch-name nonces. Set `PROJECT_NONCE` on each GitHub environment. The new
  value creates a new install, so tear down the old stacks and buckets.
