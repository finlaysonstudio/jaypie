## Changes

### Bug Fixes

- Quote the `summary` frontmatter value in `fabric/0.3.9.md` and
  `lambda/1.2.6.md`. Both contained an unquoted `: `, which YAML read as a
  nested mapping key, so the block failed to parse and `release_notes` returned
  the notes without `date` or `summary` (issue #566).

### New Features

- Add `documentFrontmatter.spec.ts`: every markdown file under `release-notes/`
  and `skills/` must parse, and every release note must carry `date`,
  `summary`, and `version`. A malformed block now fails the build.

### Documentation

- `skills/releasenotes.md` and `packages/mcp/CLAUDE.md` state when a `summary`
  requires double quotes.
