## Changes

- **`@jaypie/mcp/http`** (#539). `mcpHttpHandler` serves any fabric
  `ServiceSuite` as MCP streamable HTTP without `@modelcontextprotocol/sdk`.
  Stateless JSON-RPC 2.0 on one endpoint: `initialize`, `ping`, `tools/list`,
  `tools/call`, notifications, and batches. The `Accept` header selects a
  buffered JSON body or an SSE stream. Notification-only requests answer 202;
  GET and DELETE answer 405. Importing the entry loads no SDK modules.

  ```typescript
  import { mcpHttpHandler } from "@jaypie/mcp/http";

  app.all("/mcp", mcpHttpHandler({ services: ["skill", "version"] }));
  export const handler = createLambdaStreamHandler(app);
  ```

  Deploy behind a `RESPONSE_STREAM` function URL for streamed responses.
- **`services` allowlist**. `createMcpServer`, `mcpExpressHandler`, and
  `mcpHttpHandler` accept `services?: string[]`. Omitted exposes every service;
  `[]` exposes none; unknown names are ignored.
- **Documentation** (#535, #537, #538). `EXAMPLE.md` lists the four router tools
  and awaits `mcpExpressHandler`. Skills show `JaypieLambda` with `code` and
  `handler`, drop the claim that `jaypie` re-exports `@jaypie/dynamodb`, document
  sparse index removal, the Lambda adapter `host` fallback and `name` option, and
  every Datadog key variable.

## Dependencies

`@jaypie/express`, `@jaypie/logger`, and `express` are optional peer
dependencies, required only by `@jaypie/mcp/http`. The CLI does not install
them.
