## Changes

- **`JaypieDistribution` `zone`** falls back to
  `CDK_ENV_API_HOSTED_ZONE || CDK_ENV_HOSTED_ZONE`, matching `host` and
  `JaypieCertificate`. Previously `zone` read only `CDK_ENV_HOSTED_ZONE`, so a
  stack setting only `CDK_ENV_API_HOSTED_ZONE` resolved a host but created no
  certificate or DNS records.

## Upgrade

A stack that sets both variables to different zones now places the certificate
and DNS records in the `CDK_ENV_API_HOSTED_ZONE` zone. Pass `zone` explicitly to
keep the previous zone.

Jaypie 2 consolidates on `CDK_ENV_HOSTED_ZONE` alone.
