## Changes

- **`JaypieMigration`** accepts `memorySize` and `ephemeralStorageSize`,
  forwarded to the wrapped `JaypieLambda` (#638).
- **`JaypieMigration`** retains the log group it creates by default
  (`logRemovalPolicy`, default `RemovalPolicy.RETAIN`). A failed create rolls
  back without deleting the migration's logs, so the error behind
  `An unhandled error occurred` stays readable.
- **`JaypieLambda`** accepts `logRemovalPolicy` for the log group it creates
  (default `RemovalPolicy.DESTROY`, unchanged).

## Upgrade

- Existing `JaypieMigration` log groups switch to `Retain`. Deleting the stack
  leaves the group behind, expiring under `logRetention`. Pass
  `logRemovalPolicy: RemovalPolicy.DESTROY` to keep the previous behaviour.
