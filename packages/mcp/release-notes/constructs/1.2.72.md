## Features

- `variables` on `JaypieLambda` (and `JaypieQueuedLambda`, `JaypieMigration`,
  and the subclasses) writes non-secret values to an SSM parameter instead of
  the Lambda environment. Only a pointer occupies the 4KB budget.
- Accepts the same shapes as `environment`: an object, an array of
  `process.env` keys, or a mixed array.
- The parameter uses intelligent tiering, allowing up to 8KB, and is named
  `/{PROJECT_ENV}/{PROJECT_KEY}/{PROJECT_NONCE}/{path within stack}/variables`.
  The path within the stack is used so wrapped lambdas that share an inner
  construct id do not collide.
- Read permission is granted to the function. The handler lifecycle hydrates
  the bundle into `process.env`, so application code reads `process.env.X`
  with no resolver function.
- New `constructParameterName` helper.

Addresses issue #443.
