## Changes

- **`JaypieLambda` `tables`** grants `dynamodb:Query` and `dynamodb:Scan` on
  `${tableArn}/index/*` for every table. CDK adds index ARNs only for indexes
  declared in CDK, so a Lambda could not query a GSI created by a migration or
  owned by an imported table (#546).
- **`JaypieMigration`** inherits the grant, so a migration can query an index an
  earlier migration created in the same deploy.

## Upgrade

Remove workarounds that add `dynamodb:Query` or `dynamodb:Scan` on
`${tableArn}/index/*` to a `JaypieLambda` or `JaypieMigration` role.
