## Changes

- **`JaypieSsoPermissions` Agent set** no longer carries the
  `AgentDenyDestructive` statement. The inline policy holds `AgentWrite`,
  `AgentDenyIdentity`, and `AgentDenyPrivilegedPassRole`.
- The Agent set's description drops "no deletion".

## Upgrade

- The set alone grants nothing new: no `AgentWrite` action matched the removed
  deny list.
- A customer managed policy linked to the Agent set can now grant resource
  deletion, mass-expiry, resource-policy writes, and CloudFormation writes.
  Before, the deny overrode those grants. Review linked policies and scope any
  such grant narrowly.
- Consumers that filtered `AgentDenyDestructive` out of a copied Agent policy
  can remove the filter.
