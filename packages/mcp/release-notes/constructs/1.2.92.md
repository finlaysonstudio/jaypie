## Changes

- **`JaypieWebDeploymentBucket` `host`** accepts an array of strings,
  `HostConfig` objects, or `{ host, zone }` entries (#634). The first entry is
  primary: certificate `domainName`, un-suffixed `AliasRecord` construct ID,
  and the new `.host`. Remaining entries become certificate subject alternative
  names. Every entry lands in `domainNames` and gets an A record. `.hosts`
  exposes the resolved list.
- A `{ host, zone }` entry names the hosted zone for a host outside `zone`.
  Its certificate validation and alias record land there.
- `resolveCertificate` takes `zones`, a map of domain name to hosted zone, and
  validates through `fromDnsMultiZone` when names span zones.
- With a caller `certificate`, every host is still aliased and recorded.
- A host with no zone throws `ConfigurationError` when the construct creates
  the certificate.

## Upgrade

- Single-host usage synthesizes the same template.
- Replace an `Aliases` property override, caller-built certificate, and
  caller-built records with a `host` array.
