## Changes

- **`constructTagger`** adds `buildDate`, `buildHex`, `buildTime`, `commit`, and
  `version` with `excludeResourceTypes` for `AWS::DynamoDB::GlobalTable` and
  `AWS::DynamoDB::Table`. These tags changed every synth, forcing a table update
  on every deploy. A table whose GSIs a migration created rejects that update
  with `Invalid AttributeDefinitions`, so every deploy after the first rolled
  back (#548).
- **`JaypieInfrastructureStack`** applies the same exclusion to `stackSha`.

## Upgrade

Tables deployed with earlier versions carry the build tags. The first deploy on
this version removes them, which is a table update. A table with no
migration-owned indexes updates normally. A table with migration-owned indexes
fails that update: recreate the table or declare its indexes in CDK.
