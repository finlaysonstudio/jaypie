## Changes

- **`JaypieDatadogForwarder` reserved concurrency** defaults to `"30"` (was
  `"10"`).

## Upgrade

- Existing forwarders reserve 30 concurrent executions on the next deploy,
  drawing 20 more from the account's unreserved pool. Pass
  `reservedConcurrency: "10"` to keep the old value.
