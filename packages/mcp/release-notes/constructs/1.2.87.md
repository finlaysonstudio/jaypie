## Changes

- **`JaypieStack`** warns at synth (`@jaypie/constructs:projectNonceFormat`)
  when `CDK_DEFAULT_ACCOUNT` is set and `PROJECT_NONCE` is unset or does not
  match `^[0-9a-f]{6,}$`. A word or branch-name nonce lands in immutable stack
  names and global S3 bucket names, where it repeats across projects and
  accounts (#554).

## Upgrade

- A stack deployed with a non-hex nonce keeps warning. Stack and bucket names
  cannot be renamed: acknowledge `@jaypie/constructs:projectNonceFormat`, or
  deploy a new install with a hex nonce and tear down the old one.
