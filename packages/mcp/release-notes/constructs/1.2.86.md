## Changes

- **`JaypieMigration`** grants `DescribeTable`, `DescribeTimeToLive`, and
  `DescribeContinuousBackups` only. `UpdateTable`, `UpdateTimeToLive`, and
  `UpdateContinuousBackups` are removed: a GSI a migration creates blocks every
  later CloudFormation update to the table (#552).
- **`JaypieMigration`** warns at synth when a `JaypieDynamoDb` in `tables`
  declares no `indexes`. Acknowledge
  `@jaypie/constructs:migrationTableWithoutIndexes` for tables that need none.
- **`JaypieDynamoDb`** sorts `indexes` by name, so
  `indexes: getAllRegisteredIndexes()` synthesizes the same template regardless
  of import order, and exposes the sorted list as `indexes`.
- **`constructTagger`** and **`JaypieInfrastructureStack`** apply per-build tags
  to DynamoDB tables again, reverting 1.2.85.
- **`JaypieSecret`** and **`JaypieEnvSecret`** accept `external: true`, which
  creates an empty secret whose value never enters the template, assets
  bucket, `cdk.out`, or `cdk diff`. An `ExternalArn` output described by the
  `envKey` locates the secret for CI `put-secret-value` (#551).
- **`JaypieSsoSyncApplication`** accepts `googleCredentialsSecret` and
  `scimEndpointAccessTokenSecret` and deploys SSOSync as "App only" with six
  secret ARNs in `CrossStackConfig`. Literal credentials still work and warn
  at synth (`@jaypie/constructs:ssoSyncLiteralCredentials`).

## Upgrade

- Declare every registered index in `JaypieDynamoDb` `indexes`.
- A table with GSIs created outside CDK fails the first deploy on this version,
  because build tags update the table. CloudFormation cannot adopt those
  indexes: declare them and recreate the table. See `skill("dynamodb")`.
- Migrations that call `UpdateTable`, `UpdateTimeToLive`, or
  `UpdateContinuousBackups` fail with `AccessDenied`. Move those settings into
  `JaypieDynamoDb`.
- Add indexes to an existing table one per deploy.
- Moving `JaypieSsoSyncApplication` to secret props deletes the SAR-created
  `SSOSync*` secrets. Sync fails until CI writes the new secret values. See
  `skill("secrets")`.
