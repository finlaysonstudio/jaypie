## Changes

- **`roleTag`** (#536) documents `@default CDK.ROLE.API`, matching the
  constructor. It previously claimed `CDK.ROLE.HOSTING`.
- **`host`** documents that `CDK_ENV_API_HOST_NAME` is checked first, then
  `CDK_ENV_API_SUBDOMAIN` merged with `CDK_ENV_API_HOSTED_ZONE || CDK_ENV_HOSTED_ZONE`.
- **`zone`** documents `@default CDK_ENV_HOSTED_ZONE`. The code does not read
  `CDK_ENV_API_HOSTED_ZONE` for the zone.

No runtime behavior changed.
