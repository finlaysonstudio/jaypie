## @jaypie/constructs 1.2.79

### Features

- **JaypieSsoPermissions**: Added an `Agent` permission set between Analyst and
  Developer, with `agentGroupId` and `agentAccountAssignments` props and an
  `agentPermissionSet` property. It carries `ReadOnlyAccess` plus data-plane and
  operational writes (item, object, and message writes; Lambda invoke and
  configure; ECS tasks; Step Functions executions; `secretsmanager:GetSecretValue`)
  and denies deletion, resource-policy writes, CloudFormation mutation, identity
  change, and `sts:AssumeRole`. Session duration is 8 hours.
- **JaypieSsoPermissions**: Added `support-console:*` to the Developer permission
  set inline policy, allowing developers to open and manage AWS Support cases
