## Changes

- **Datadog forwarder invoke permissions.** `resolveDatadogForwarderFunction`
  and `JaypieDatadogForwarder` import the forwarder with
  `fromFunctionAttributes({ sameEnvironment: true })`. `fromFunctionArn` on a
  token ARN yields an unresolved environment, so `addPermission()` was a silent
  no-op and every trigger deployed without invoke permission (#560).
  `JaypieDatadogForwarder` acknowledges
  `@aws-cdk/aws-events:ruleUnresolvedEnvironment` on its own events rule.
- **Hardened default log buckets.** The CloudFront access log bucket and WAF log
  bucket that `JaypieDistribution` and `JaypieWebDeploymentBucket` create now
  block all public access, enforce SSL, are versioned, use SSE-S3, expire
  objects after `logRetention` (365 days by default, new prop), and carry
  `RemovalPolicy.RETAIN` with no auto-delete. The WAF bucket policy declares the
  `delivery.logs.amazonaws.com` statements so CloudFormation owns it (#561).
- **`JaypieDistribution` origin access control.** `originAccessControl: true`
  creates an `AWS_IAM` Function URL, uses
  `FunctionUrlOrigin.withOriginAccessControl`, and adds the
  `lambda:InvokeFunction` permission Lambda requires alongside
  `lambda:InvokeFunctionUrl`. Opt-in; the default stays `authType: NONE` (#562).
- **`JaypieWebDeploymentBucket` origin access control.**
  `originAccessControl: true` serves a private bucket through the S3 REST
  endpoint with OAC, `BLOCK_ALL`, `enforceSSL`, no website configuration, and
  `defaultRootObject: "index.html"`. Opt-in; the default stays the public S3
  website bucket (#563).
- **WAF log redaction.** The `waf` config accepts `redactedHeaders` (default
  `["authorization", "cookie", "x-amz-content-sha256", "x-api-key"]`) and a
  `redactedFields` passthrough for query strings, URI paths, and JSON body
  fields (#564).
- **`JaypieMigration` log props.** `logGroup`, `logRetention`, and
  `reservedConcurrentExecutions` forward to the wrapped `JaypieLambda` (#565).

## Upgrade

- **Log buckets survive stack deletion.** The CloudFront log bucket moves from
  `DESTROY` with auto-delete to `RETAIN`. Deleting a stack now leaves the bucket
  and its objects behind as a billable resource to remove by hand.
- **Retention rises from 90 to 365 days** on the construct-created log buckets,
  roughly quadrupling retained volume. Pass `logRetention: 90` to keep the old
  value. Versioning is a one-way door on an existing bucket.
- **The WAF log bucket gains a CloudFormation-owned bucket policy.** Any
  statement added to that bucket out of band is discarded on the next deploy.
- **Existing WAF logging configurations gain `RedactedFields`** on the next
  deploy. Pass `redactedHeaders: []` to keep logging every header.
- **Datadog forwarder triggers gain `AWS::Lambda::Permission` resources** on the
  next deploy, and S3 notification configurations that previously failed
  validation now apply.
- `originAccessControl` is opt-in on both constructs; no existing deployment
  changes without setting it. With it enabled on `JaypieDistribution`, clients
  must send the body SHA-256 in `x-amz-content-sha256` on POST and PUT.
