## Changes

- `JaypieLogger` exposes a read-only `sessionActive` getter, `true` between
  `setup()` and `teardown()`
- Libraries that tally opportunistically guard on it rather than calling
  `tally()` unconditionally and having the logger trace
  `[logger] tally() called without active session`

## Usage

```typescript
if (log.sessionActive !== false) {
  log.tally({ llm: { operates: 1, turns: 2 } });
}
```

Compare against `false` rather than testing truthiness: a logger predating this
release reports `undefined`, where the tally should still be attempted.
