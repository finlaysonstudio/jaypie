## Changes

- `log.report()` merges plain objects recursively (#585). Two calls that
  write different children of the same key keep both
- Arrays and scalars are leaves where the last write wins. A changed leaf logs
  `[logger] Overwriting report key: <dotted.path>` at debug; rewriting the
  same value logs nothing

## Usage

```typescript
log.report({ agentModel: { agent_notes: { chain: "Fast" } } });
log.report({ agentModel: { agent_evidence_list: { chain: "Fast" } } });
// => teardown report includes both agent_notes and agent_evidence_list
```

Use `log.tally()` for values that accumulate; `report()` is for data
recorded once, including nested data filled in across several calls.
