## Changes

- **`init()` warns on an active session** (#629). Calling `init()` between
  `setup()` and `teardown()` logs
  `[logger] init() called while session active; session reset` instead of
  resetting silently. Overlapping requests in one process (local Express,
  supertest) surface as this warning. Per-request sessions are planned for
  Jaypie 2.0 (#630).
