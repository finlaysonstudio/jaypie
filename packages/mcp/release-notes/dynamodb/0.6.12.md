## Changes

- **`preserveTimestamps` opt-in** (#580). `createEntity`, `updateEntity`, and
  `transactWriteEntities` accept `preserveTimestamps: true`, and
  `seedEntities` accepts it as an option. With the flag, the entity's own
  `createdAt` and `updatedAt` are kept (each falls back to now when missing),
  so `scope#updatedAt` sort keys reflect when the item happened. TTL handling,
  date serialization, and conditional-write error mapping still apply.
- **`indexEntity(entity, options?)`** takes `{ preserveTimestamps?, suffix? }`
  in place of the positional `suffix` string. `IndexEntityOptions` is
  exported.

## Migration

- `indexEntity(entity, "#deleted")` becomes
  `indexEntity(entity, { suffix: "#deleted" })`.
