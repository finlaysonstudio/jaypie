## Changes

- **`patchEntity({ id, set?, remove?, condition?, names?, values? })`** (#606).
  Sends a targeted `UpdateItem` that sets and removes only the listed
  attributes. `updatedAt` and every GSI key stay unchanged, so the entity
  keeps its place in `queryByScope` and other index queries, and concurrent
  writes to other fields are never overwritten with a stale copy. Returns the
  entity as stored after the write.
- Protected attributes (`id`, `model`, `updatedAt`, `archivedAt`, `deletedAt`,
  `index*`, and every pk/sk field of a registered index) throw
  `BadRequestError`; change those with `updateEntity`. A missing entity throws
  `NotFoundError`; a failed `condition` throws `ConflictError`.
- **Docs:** `updateEntity` and `queryByScope` documentation explains that each
  `updateEntity` moves the entity's `indexModel` entry, and recommends
  `patchEntity` for counters, heartbeats, and "last X" fields.
