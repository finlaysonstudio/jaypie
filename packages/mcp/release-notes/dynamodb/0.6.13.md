## Changes

- **`destroyTable` fails clearly** (#582). Calling `destroyTable()` with no
  arguments, or with an empty `tableName`, throws a `ConfigurationError`
  before any AWS call. It previously died on destructuring with a raw
  `TypeError`. `tableName` still has no default: deleting a table must name
  it explicitly.
