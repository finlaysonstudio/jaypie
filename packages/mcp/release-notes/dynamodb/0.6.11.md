## Changes

- **Sparse indexes can be exited** (#533). Through `@jaypie/fabric` 0.3.12,
  `indexEntity` drops a stale index key (for example `indexModelCategory` and
  `indexModelCategorySk`) when its source field is absent. `updateEntity` writes
  the entity with a full PUT, so deleting `category` and updating removes the
  row from `indexModelCategory`.
